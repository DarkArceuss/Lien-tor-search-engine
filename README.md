# Lien Search Engine
![](https://i.ibb.co/23Q4KkTY/Untitled51-20260911213553.png)
**Lien** — private, simple and local search engine, based on [Onion Hoster by uzair dev](https://github.com/uzairdeveloper223/Onion-Hoster).An excellent choice for people who want **simplicity and privacy on mobile.**
## How install **Lien** in termux?
1. Copy my repository:
```bash
git clone
cd ~/Lien_startup
```
2. Give permission and activate **panel.sh**:
```bash
chmod +x panel.sh
```
And run panel:
```bash
bash panel.sh
```
3. Select **Activation** and wait. Then copy .onion link and pate her in **[Tor Browser](https://www.torproject.org/)**
### How stop server?
In other tab activate **panel.sh** again and select Stop server.
